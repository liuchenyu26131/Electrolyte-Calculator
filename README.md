# 钠钾镁锌摄入计算器

钠、钾、镁、锌每日摄入量计算工具，用于正分子营养科研参考。

## 目录结构

```
.
├── index.html           # 计算器页面（纯静态，可部署到 GitHub Pages）
├── README.md            # 本文件
├── csv/
│   └── 钠钾镁离子平衡_20260726.csv   # 原始产品数据（维护溯源）
└── data/
    └── products.json    # 结构化产品数据（HTML 实际加载的源）
```

## 使用说明

1. 选取产品 × 数量
2. 添加后自动计算钠、钾、镁、锌的累计摄入量
3. 进度条直观显示与每日目标的差距
4. "生成补充建议"按钮自动计算缺口并推荐单品/复合产品
5. 睡前补充区可标记钙和镁的睡前摄入

## 数据维护

### 修改产品数据

编辑 `data/products.json` 中的对应字段，无需修改 `index.html`。

### 数据来源

原始数据在 `csv/` 目录下，以 CSV 格式留存溯源码。

## 部署

`index.html` 是纯静态页面，可直接部署到：

- **GitHub Pages** — 推送至仓库根目录即可
- **Cloudflare Pages / Netlify** — 直接连接仓库或拖拽上传
- **任意静态文件服务器** — Nginx / Apache / S3

页面启动时会通过 `fetch('data/products.json')` 加载数据，并缓存到 `localStorage` 以便离线使用。
